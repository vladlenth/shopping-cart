# Техническое задание: Приложение "Корзина покупок"

## Обзор проекта

Приложение "Корзина покупок" — это учебный проект для курса React от The Odin Project. Это одностраничное приложение (SPA), разработанное с использованием Vite, TypeScript, React, Redux Toolkit, Axios, React Query и TanStack Router, с акцентом на типобезопасность и современный адаптивный дизайн.

## Технологический стек

- **Фреймворк**: React с TypeScript
- **Инструмент сборки**: Vite
- **Управление состоянием**: Redux Toolkit
- **HTTP-клиент**: Axios
- **Загрузка данных**: React Query (TanStack Query)
- **Роутинг**: TanStack Router
- **API**: FakeStore API (https://fakestoreapi.com/products)
- **Стилизация**: На выбор один из вариантов CSS и UI-кита (см. ниже)

### Варианты стилизации и UI-китов

1. **Tailwind CSS**:
   - **Описание**: Утилитарный CSS-фреймворк для быстрого создания адаптивных интерфейсов.
   - **Преимущества**: Высокая гибкость, минимальный CSS-код, встроенная адаптивность, поддержка тем.
   - **Использование**: Установить через npm, настроить в `tailwind.config.js` для кастомизации (например, цвета, шрифты). Подходит для создания компонентов с нуля.
   - **Пример**: Стилизация карточек товаров с помощью классов `flex`, `grid`, `p-4`, `bg-white`, `shadow-md`.

2. **Styled Components**:
   - **Описание**: Библиотека CSS-in-JS для написания стилей в JavaScript с использованием тегированных шаблонных строк.
   - **Преимущества**: Полная изоляция стилей, динамические стили на основе пропсов, поддержка TypeScript.
   - **Использование**: Установить через npm (`styled-components`), создавать стилизованные компоненты (например, `const Card = styled.div`...``).
   - **Пример**: Создание карточки товара с динамическими стилями для hover-эффектов.

3. **Material-UI (MUI)**:
   - **Описание**: Популярный UI-кит для React с готовыми компонентами, соответствующими принципам Material Design.
   - **Преимущества**: Богатый набор компонентов (кнопки, карточки, модальные окна), встроенная поддержка тем, доступность.
   - **Использование**: Установить через npm (`@mui/material`, `@emotion/react`, `@emotion/styled`), настроить тему в `ThemeProvider`.
   - **Пример**: Использование компонентов `Card`, `Button`, `TextField` для карточек товаров и форм.

4. **Chakra UI**:
   - **Описание**: UI-кит с модульной системой компонентов и упором на доступность и простоту.
   - **Преимущества**: Встроенная поддержка тем, адаптивные стили, интеграция с Emotion для CSS-in-JS.
   - **Использование**: Установить через npm (`@chakra-ui/react`, `@emotion/react`, `@emotion/styled`), настроить `ChakraProvider`.
   - **Пример**: Использование `Box`, `Image`, `Input` для создания карточек и форм с адаптивными стилями.

**Рекомендация**: Использовать Tailwind CSS для максимальной гибкости и скорости разработки или Chakra UI для быстрого старта с готовыми компонентами и встроенной адаптивностью.

- **Компоненты**:
  - `Navbar`: Навигационная панель с ссылками на "Главная", "Магазин" и "Корзина" (отображает количество товаров в корзине в реальном времени).

### 4. Настройка API

- **Axios Instance**:

  ```typescript
  import axios from 'axios';

  const api = axios.create({
    baseURL: 'https://fakestoreapi.com',
  });

  export default api;
  ```

- **Объект запросов**:

  ```typescript
  import api from './api';
  import { Product } from '../types';

  export const productApi = {
    getProducts: async (): Promise<Product[]> => {
      const response = await api.get('/products');
      return response.data;
    },
    getProductById: async (id: number): Promise<Product> => {
      const response = await api.get(`/products/${id}`);
      return response.data;
    },
  };
  ```

### 5. React Query с иерархией ключей

- Использовать React Query для загрузки данных и управления кэшем.
- Определить иерархию ключей через объект:
  ```typescript
  export const queryKeys = {
    products: {
      all: ['products'] as const,
      byId: (id: number) => ['products', id] as const,
    },
  };
  ```
- Пример использования в хуке:

  ```typescript
  import { useQuery } from '@tanstack/react-query';
  import { productApi } from './productApi';
  import { queryKeys } from './queryKeys';

  export const useProducts = () => {
    return useQuery({
      queryKey: queryKeys.products.all,
      queryFn: productApi.getProducts,
    });
  };

  export const useProductById = (id: number) => {
    return useQuery({
      queryKey: queryKeys.products.byId(id),
      queryFn: () => productApi.getProductById(id),
    });
  };
  ```
